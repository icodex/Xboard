## 合并带来的行为变化（记录备查）

- `v2_user.email` 改 `utf8mb4_bin`（MySQL），PG/SQLServer 各自对应；迁移先 `assertNoEmailCollisions()`，规范化后撞车或超 64 字符直接失败并报出用户 ID。
- 后台邮箱 LIKE 搜索改为先 `User::normalizeEmail`（UserController 字段过滤、TrafficResetController、TicketController），因为二进制排序规则下 LIKE 变成大小写敏感。
- `Client` 中间件 token 收紧为 32 位 hex，且只读 route/query（不再读 `input()`）。本仓所有 token 赋值点均为 `Helper::guid()`（md5 32 hex），安全；非 hex 的历史 token 订阅会 403。
- `setInviteUser`：`AdminRoute.php:137` 路由早已存在但实现缺失，本次合并补上（含环形邀请校验）。
